# Rubric loại bài — Comparison / Listicle (từ `listicle-comparison-writing`)

Mỗi tiêu chí: **0 / 0.5 / 1**. Tổng 7 mục → quy về thang 10 (nhân 10/7).

| # | Tiêu chí | Blocker? |
|---|----------|:--------:|
| P1 | Tiêu chí so sánh **khách quan, nhất quán** cho cả hai bên. | |
| P2 | Có **bảng so sánh** theo tiêu chí. | |
| P3 | Số liệu/benchmark (nếu có) **có nguồn + điều kiện đo**; không bịa. | 🔴 (nếu bịa benchmark) |
| P4 | **Tuyên bố tính năng có link tài liệu chính thức** (không chỉ số liệu mới cần nguồn). | |
| P5 | **Trung lập:** nêu cả ưu và nhược mỗi bên; không thiên vị. | |
| P6 | So sánh **cùng phiên bản/điều kiện**, ghi rõ (kiểm bản mới nhất). | |
| P7 | Kết luận là **khuyến nghị theo ngữ cảnh** ("chọn X nếu..."), không phán "tốt nhất tuyệt đối". | |

## Điểm trượt điển hình của model yếu
- Thiên vị một bên (P5).
- Bảng đầy tuyên bố tính năng nhưng **không link nguồn nào** (P4) — gap lặp lại đã thấy khi test.
- Bịa benchmark (P3 🔴); kết luận "X tốt nhất" không nêu ngữ cảnh (P7).

## Cách quy điểm
`điểm loại bài = (tổng 7 mục) × 10 / 7`. Ghi rõ mục 🔴 vi phạm để áp trần 4/10.
