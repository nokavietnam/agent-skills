# Rubric loại bài — AI Coding Tips (từ `ai-coding-tips-writing`)

Mỗi tiêu chí: **0 / 0.5 / 1**. Tổng 7 mục → quy về thang 10 (nhân 10/7).

| # | Tiêu chí | Blocker? |
|---|----------|:--------:|
| A1 | Mỗi mẹo có **ví dụ cụ thể** (không nói suông). | |
| A2 | Ví dụ prompt **trước/sau** đặt trong **code block**. | |
| A3 | Mẹo là **nguyên tắc chung**, không phụ thuộc giao diện/nút bấm một công cụ. | |
| A4 | **Nêu rõ rủi ro của AI** (hallucination, bảo mật, license) — phần bắt buộc. | 🔴 (nếu khuyên tin AI mù quáng / bỏ hẳn phần rủi ro) |
| A5 | Nhấn mạnh **con người review + test + hiểu trước khi merge**. | |
| A6 | **Trung lập công cụ** (không thiên vị/PR một sản phẩm). | |
| A7 | Ghi **mốc thời gian / lưu ý giao diện có thể đổi**; không thổi phồng năng suất. | |

## Điểm trượt điển hình của model yếu
- Mẹo nói suông không ví dụ prompt (A1, A2).
- Bám vào giao diện một công cụ cụ thể (A3).
- **Quên hoàn toàn phần rủi ro AI** (A4 🔴) — lỗi hay gặp nhất.
- Thổi phồng "AI viết cả app trong 5 phút" (A7).

## Cách quy điểm
`điểm loại bài = (tổng 7 mục) × 10 / 7`. Ghi rõ mục 🔴 vi phạm để áp trần 4/10.
