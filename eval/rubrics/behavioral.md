# Rubric loại bài — Behavioral Interview (từ `behavioral-interview-writing`)

Mỗi tiêu chí: **0 / 0.5 / 1**. Tổng 8 mục → quy về thang 10 (nhân 10/8).

| # | Tiêu chí | Blocker? |
|---|----------|:--------:|
| H1 | Nhấn mạnh **chân thật**: dạy kể chuyện thật, **không khuyến khích bịa thành tích**. | 🔴 (nếu khuyến khích bịa) |
| H2 | Giải thích **STAR** (Situation/Task/Action/Result) đúng, đủ; thêm **L (Learning)** cho câu hỏi thất bại. | |
| H3 | Có **ví dụ trước/sau** (yếu vs mạnh). | |
| H4 | Ví dụ mẫu **đánh dấu rõ là mẫu minh họa**, không trình bày như chuyện thật của người cụ thể. | 🔴 (nếu dựng chuyện giả như thật) |
| H5 | Action ở **ngôi "tôi"**; Result **định lượng** khi có thể. | |
| H6 | Nêu **điều nhà tuyển dụng thực sự muốn** (tự nhận thức, học hỏi...). | |
| H7 | STAR trình bày như **khung linh hoạt**, không phải kịch bản đọc thuộc. | |
| H8 | Có **cách chuẩn bị** (kho câu chuyện từ trải nghiệm thật). | |

## Điểm trượt điển hình của model yếu
- Gợi ý "thất bại giả" (điểm mạnh trá hình) hoặc đổ lỗi (H1 🔴).
- Đưa câu chuyện mẫu như thể là thật của một người (H4 🔴).
- STAR thiếu phần, hoặc câu trả lời chung chung không ngôi "tôi" (H2, H5).

## Cách quy điểm
`điểm loại bài = (tổng 8 mục) × 10 / 8`. Ghi rõ mục 🔴 vi phạm để áp trần 4/10.
