# Prompt test — Comparison (X vs Y)

**Skill cần nạp:** `blog-foundations` + `listicle-comparison-writing` + skill chủ đề (ví dụ `backend-engineering-writing`).

**Rubric chấm:** `rubrics/_common.md` + `rubrics/comparison.md`.

---

## Prompt (dán nguyên văn cho model)

```
Viết một bài blog so sánh bằng tiếng Việt: "PostgreSQL vs MySQL — chọn cái nào cho dự án của bạn?".

Bài phải so sánh theo tiêu chí khách quan nhất quán cho cả hai bên, có bảng so sánh, dẫn nguồn
cho các tuyên bố tính năng (không chỉ số liệu), trung lập (nêu cả ưu và nhược mỗi bên), và kết
luận là khuyến nghị theo ngữ cảnh chứ không phán "cái nào tốt nhất tuyệt đối".
```

---

## Ghi chú cho người chấm

- Nếu skill hoạt động: tiêu chí khách quan nhất quán hai bên; bảng so sánh; **tuyên bố tính năng có link tài liệu chính thức** (không chỉ số liệu mới cần nguồn); trung lập; kết luận "chọn X nếu..., chọn Y nếu...".
- Điểm trượt hay gặp ở model yếu: thiên vị một bên; bảng đầy tuyên bố tính năng nhưng **không link nguồn nào**; bịa benchmark; kết luận "X tốt nhất" không nêu ngữ cảnh; chép mô tả marketing.
