# Prompt test — AI Coding Tips

**Skill cần nạp:** `blog-foundations` + `ai-coding-tips-writing`.

**Rubric chấm:** `rubrics/_common.md` + `rubrics/ai-coding-tips.md`.

---

## Prompt (dán nguyên văn cho model)

```
Viết một bài blog bằng tiếng Việt chia sẻ các mẹo prompt để công cụ AI (Copilot, Cursor,
Claude Code...) sinh code sạch hơn.

Mỗi mẹo phải có ví dụ prompt trước/sau, là nguyên tắc chung (không phụ thuộc giao diện một
công cụ cụ thể), và bài phải nêu rõ rủi ro của AI cùng việc con người chịu trách nhiệm cuối.
```

---

## Ghi chú cho người chấm

- Nếu skill hoạt động: mỗi mẹo có ví dụ prompt **trước/sau** trong code block; nguyên tắc chung không phụ thuộc UI; **mục rủi ro AI bắt buộc** (hallucination, bảo mật, license); nhấn mạnh review + test + hiểu trước khi merge; trung lập công cụ + ghi mốc thời gian.
- Điểm trượt hay gặp ở model yếu: mẹo nói suông không ví dụ; bám vào nút bấm/giao diện một công cụ; **quên hoàn toàn phần rủi ro AI**; thổi phồng ("AI viết cả app trong 5 phút"); thiên vị một công cụ.
